\# Education-Project



This project focuses on tracking and analyzing student performance using the CollegeDatabase dataset.



\## Dataset

The dataset includes structured information about students, courses, and enrollments.

Dataset source: \[CollegeDatabase on Kaggle](https://www.kaggle.com/datasets/yashnarkhede1998/collegedatabase?utm\_source=chatgpt.com)



\## Project Goals

\- Analyze student performance

\- Visualize enrollments and grades

\- Explore educational insights
